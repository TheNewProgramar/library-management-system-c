# 📚 Library Management System

A command-line library management system written in C.

## ✨ Features

- ✅ Add books
- ✅ Add members
- ✅ Borrow books
- ✅ Return books
- ✅ Search books
- ✅ View all books
- ✅ Save/Load data
- ✅ Dynamic memory allocation

## 🛠️ Planned Features

- [ ] Book categories
- [ ] Due date tracking
- [ ] Fine calculation
- [ ] Member cards
- [ ] ncurses GUI

## 🚀 How to Compile

```bash
gcc -Wall -Wextra -o library main.c
```
## 🏃 How to Run
```bash
./library
```
## 📝 Usage
```text
===== LIBRARY MANAGEMENT =====
1. Add Book
2. View Books
3. Search Book
4. Add Member
5. Borrow Book
6. Return Book
7. Exit
==============================
```
