# 📚 Library Management System

A command-line library management system written in C.

## ✨ Features

- ✅ Add books
- ✅ Add members
- ✅ Borrow books
- ✅ Return books
- ✅ Search books
- ✅ View all books
- ✅ Save/Load data
- ✅ Dynamic memory allocation
