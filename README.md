# 📚 Library Management System

A command-line library management system written in C.

## ✨ Features
- ✅ Add/View Books
- ✅ Add/View Members
- ✅ Borrow/Return Books
- ✅ Search Books
- ✅ Save/Load Data
- ✅ ncurses GUI with colors
- ✅ Arrow key navigation
- ✅ Dynamic memory allocation
- ✅ Status bar
--------------------------------------------------

## 🚀 How to Compile

```bash
gcc -Wall -Wextra -o library main.c
```
## 🏃 How to Run
```bash
./library
```
## 📝 Usage
```text
===== LIBRARY MANAGEMENT =====
1. Add Book
2. View Books
3. Search Book
4. Add Member
5. Borrow Book
6. Return Book
7. Exit
==============================
```
